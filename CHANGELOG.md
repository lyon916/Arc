# Changelog

All notable changes to Arc will be documented in this file.

## [1.0.0] - 2026-06-03

### Added
- HTTP Request Builder: GET / POST / PUT / DELETE / PATCH / HEAD / OPTIONS
- Query Params, Headers, Body editor (JSON / FormData / Raw)
- Bearer Token and Basic Auth support
- Environment variables with `{{varname}}` syntax
- Collections (save and organize requests with folder grouping)
- Request history stored in local IndexedDB
- cURL import (paste cURL to populate a request)
- Code generation (JavaScript / TypeScript / cURL snippets)
- 17 themes (Linear Dark, Dracula, Nord, Catppuccin, Solarized, GitHub Light, etc.)
- i18n: English and Chinese (auto-detects browser language)
- Mobile responsive layout with bottom-tab navigation
- Keyboard shortcuts: Ctrl+Enter, Ctrl+S, Cmd+L, Esc
- SEO meta tags, JSON-LD, sitemap, robots.txt
- PWA manifest and favicon
- Google Analytics 4 integration
